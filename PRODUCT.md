# Product

## Register

product

## Users

SpiritVale players planning characters while already in the game. They need to compare equipment, set attribute targets, revisit saved ideas, and inspect community loadouts without breaking their play flow.

## Product Purpose

Build Crafter is an in-game planning workspace backed by the installed SpiritVale client data. It lets players assemble a character build, save and reopen builds on their own machine, import public builds from SpiritValers, and hand an item to Item Encyclopedia for deeper research when that optional mod is installed.

## Brand Personality

Focused, grounded, and companionable. It should feel like a well-made field notebook that belongs beside SpiritVale, with concise labels and dependable feedback.

## Anti-references

Avoid a browser-like form transplanted into the game, dense spreadsheet presentation, glowing sci-fi dashboards, decorative glass panels, excessive card grids, and ambiguous icon-only actions.

## Design Principles

- Keep the build visible while choices are being made.
- Make save state, data source, and import status explicit.
- Prefer progressive panels over disruptive modal dialogs.
- Preserve useful community data even when the installed game version cannot resolve an item.
- Treat optional integrations as enhancements, never as requirements.

## Accessibility & Inclusion

Support keyboard escape behavior, readable text contrast, UI scaling, clear text labels alongside symbols, color-independent selected states, and reduced reliance on motion. All error and empty states should explain a recovery action.
